紹介プライバシーポリシー利用規約

プライバシーポリシー

最終更新：2026年11月6日

local-ai-harness（以下「本ツール」）は、YouTubeチャンネルの運営者（以下「運営者」）が自分のパソコンで動かす個人用のツールです。本ツールを使うのは運営者本人だけです。このページでは、本ツールが扱う情報と、その扱い方を説明します。

Google から受け取る情報

本ツールは、運営者本人の Google アカウントでの許可にもとづき、YouTube Data API を通じて次の情報を受け取ります。

  • 運営者のチャンネルの情報（チャンネル名・チャンネルID）
  • 運営者の動画の情報（タイトル・概要欄・公開日・再生数などの統計）
  • 運営者の動画の字幕
  • 運営者の動画に寄せられた公開コメント（投稿者の表示名・チャンネルID・本文・日時・いいねの数）

情報の使い方

  • コメントへの返信案を作るため
  • どのような質問や指摘が多いかを分析し、動画づくりに生かすため
  • 運営者が承認した返信を投稿し、運営者が承認した概要欄・字幕の修正を反映するため

広告、販売、個人の特定や追跡（プロファイリング）には使いません。

保存する場所

  • 受け取った情報は、運営者のパソコンの中に保存します。
  • Google のログインの許可（アクセス用の情報）は、運営者のパソコンの中の、運営者本人だけが読める場所に保存します。

ほかのサービスに渡す情報

本ツールは、次の目的に必要な範囲でだけ、情報をほかのサービスに渡します。それ以外の第三者に提供・販売することはありません。

  • Notion（運営者自身のワークスペース）：運営者がスマートフォンで返信案を確認・承認するため、コメント本文・返信案・調べた根拠を置きます。
  • Anthropic の Claude API：専門的な質問への返信案づくりで、運営者のパソコンの中のAIだけでは足りない場合に限り、コメント本文と調べた内容を送ります。
  • 論文の検索サービス（PubMed・Europe PMC）：返信の根拠を調べるため、英語の検索語と、論文の番号（PubMed の番号・DOI）を送ります。
  • 一般のウェブ検索：論文で答えが出なかった点を調べるため、日本語または英語の一般的な検索語を送ります。検索は、運営者のパソコンの中で動く SearXNG を通じて Google・Bing・DuckDuckGo・Brave などの検索エンジンに送り、それが使えないときは Tavily に送ります。見つかった公開のウェブページは、文字だけを取得します。
  • 検索語には、コメント投稿者の名前などの個人情報や、コメントの文章そのものを含めません（パソコンの中のプログラムが確かめてから送ります）。

Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使用と、ほかのアプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

許可の取り消しと削除

  • 本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • 運営者のパソコンに保存した情報は、運営者がいつでも削除できます。
  • コメントを投稿された方で、本ツールに保存されたご自身のコメントの削除を希望される場合は、下の連絡先までご連絡ください。

YouTube と Google のポリシー

本ツールは YouTube API サービスを使用しています。YouTube 利用規約と Google プライバシーポリシーもあわせてご覧ください。

変更

このポリシーを変更する場合は、このページで更新日とともに公開します。

連絡先

本ツールやこのポリシーについての質問は、GitHub の Issue からお寄せください。

English summary

local-ai-harness is used only by the channel owner. Through the YouTube Data API it receives the owner's channel and video information, descriptions, captions, and public comments on the owner's videos (author display name, channel ID, text, date, like count). The data is used only to draft replies, analyse questions and feedback, and post replies or update descriptions and captions that the owner approves. It is stored on the owner's own computer. It is shared only with the owner's own Notion workspace (for approval), Anthropic's Claude API (for drafting difficult replies, when needed) and search services: PubMed and Europe PMC, and general web search engines (Google, Bing, DuckDuckGo, Brave and others through a SearXNG instance on the owner's computer, or Tavily when that is unavailable), which receive general search terms and paper identifiers only, never personal information or comment text; public web pages found this way are fetched as text. It is never sold or used for advertising. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: GitHub Issues
